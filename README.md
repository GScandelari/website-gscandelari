# Guilherme Scandelari — Portfólio Profissional

Site pessoal e portfólio de **Guilherme Stanke Scandelari**, Engenheiro de Suporte de Software com mais de 14 anos de experiência em TI.

**Acesse:** [website-scandelari.web.app](https://website-scandelari.web.app)

## Sobre

Este repositório contém o código-fonte do meu site pessoal, desenvolvido com HTML, Tailwind CSS e hospedado no Firebase Hosting. O site apresenta minha trajetória profissional, habilidades técnicas, projetos e formas de contato.

## Tecnologias

- HTML5 + Tailwind CSS
- Firebase Hosting
- GitHub Actions (CI/CD)

## Deploy

Pushes na branch `main` são automaticamente publicados no Firebase Hosting via GitHub Actions.
